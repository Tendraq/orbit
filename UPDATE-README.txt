Orbit update: new design, menus and features.

1. Extract this zip.
2. Copy everything inside the extracted 'orbit' folder over your project folder,
   choosing 'Replace the files in the destination'.
3. Your .env, .env.local, node_modules, package.json and pnpm-workspace.yaml are NOT touched.
4. No database change is needed. Do not run db:migrate.
5. Stop the app (Ctrl+C) and start it again with: pnpm dev
